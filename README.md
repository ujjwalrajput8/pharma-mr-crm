# Pharma MR CRM

A modern Medical Representative (MR) Management System built with React, TypeScript, Node.js, Express, Prisma, and PostgreSQL.

## 🚀 Tech Stack

### Frontend

* React
* TypeScript
* Vite
* React Router
* Tailwind CSS

### Backend

* Node.js
* Express.js
* TypeScript
* Prisma ORM
* PostgreSQL
* JWT Authentication

## 📁 Project Structure

```text
pharma-mr-crm/
├── client/
├── server/
├── shared/
├── docs/
└── README.md
```

## ✨ Features

* User Authentication (Admin / MR)
* Dashboard
* Doctor Management
* Medical Store Management
* Medicine Management
* Appointment Management
* Daily Visit Tracking
* Medicine Distribution
* Stock Management
* Reports & Analytics

## 📦 Installation

### Clone the repository

```bash
git clone <repository-url>
```

### Install dependencies

```bash
npm install
cd client && npm install
cd ../server && npm install
```

### Run the project

```bash
npm run dev
```
